# 07_Design_Patterns

This directory documents the creational, structural, and behavioral software and distributed systems design patterns used in SALESTORM.

## Planned Deliverables
- Strategy Pattern (Payment processors, discount engines)
- Saga / Outbox Pattern (Distributed transaction management & reliable messaging)
- Circuit Breaker & Retry with Exponential Backoff
- Token Bucket / Leaky Bucket (Rate limiting & surge protection)
- State Pattern (Order lifecycle transitions)
